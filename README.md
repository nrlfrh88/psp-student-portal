# PSP Student Portal (Mini Project 2)
DFP40443 Full Stack Web Development, Politeknik Seberang Perai

## Features
- Login and profile (session based)
- Change password (hashed)
- Student records CRUD (prepared statements)
- Profile picture upload (jpg, jpeg, png, max 2MB, renamed with uniqid)

## Setup
1. Import database/portal_psp.sql into MySQL
2. Edit model/conn.php with your database details
3. Open index.php in the browser
